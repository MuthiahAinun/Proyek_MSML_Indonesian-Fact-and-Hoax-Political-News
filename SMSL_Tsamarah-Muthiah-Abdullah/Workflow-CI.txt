In this stage, the complete model training and logging process is carried out in Google Colab using a GPU environment through MLflow, while the Docker image is automatically built using GitHub Actions CI to support efficient deployment automation.

- The name of the GitHub Actions workflow used (`docker-build.yaml`)
- A summary of the steps performed in the CI process:
  - Pulling the trained model from MLflow artifacts
  - Building a Docker image using MLflow’s model packaging
  - Tagging and pushing the image to Docker Hub
- Reference to the final Docker image:
